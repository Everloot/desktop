# Everloot desktop

The Everloot desktop companion: uploads what the addon recorded, answers `/ask` in game, and writes market prices back for the addon.

## What it holds

- The uploader
- The `/ask` bridge
- The price writer

## Status

Not moved yet. WoW: Forever launches on November 4, 2026; until then this code lives in
[Everloot/everloot](https://github.com/Everloot/everloot/tree/main/companion). It moves here after launch, with its history, following the
organization split plan.
